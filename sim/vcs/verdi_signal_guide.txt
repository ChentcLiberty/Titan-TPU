================================================================================
验证要点
================================================================================

Test 1 - 权重读写（大约 0-200ns）：
  1. 检查 ub_wr_host_valid_in 拉高时间
  2. 确认 memory[0:3] = 0x0100, 0x0200, 0x0300, 0x0400
  3. 查看 ub_rd_weight_data_out_0/1 在 3 个周期的输出：
     T0: W0=0x0300, W1=0x0000
     T1: W0=0x0100, W1=0x0400
     T2: W0=0x0000, W1=0x0200

Test 2 - 输入数据读写（大约 250-450ns）：
  1. 确认 memory[0:3] = 0x1000, 0x2000, 0x3000, 0x4000
  2. 查看 ub_rd_input_data_out_0/1 在 3 个周期的输出：
     T0: IN0=0x1000, IN1=0x0000
     T1: IN0=0x3000, IN1=0x2000
     T2: IN0=0x0000, IN1=0x4000

Test 3 - 行主序验证（大约 500-700ns）：
  1. 确认 memory[0:3] = 0xAA00, 0xAA01, 0xAA10, 0xAA11
  2. 验证读取顺序与 Test 2 相同

================================================================================
快捷操作
================================================================================

1. 添加信号：选中信号 → 按键盘 'a' 或右键 "Add to Waveform"
2. 设置十六进制显示：选中信号 → 右键 → Radix → Hexadecimal
3. 添加标记：在时间轴右键 → Add Marker
4. 缩放：鼠标滚轮 或 Ctrl+拖动
5. 查找信号：Ctrl+F
