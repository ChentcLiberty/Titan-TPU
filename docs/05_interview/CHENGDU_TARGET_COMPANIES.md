## 投递策略

### 时间线
- **3月1日-7日**：第一梯队全部投完（华为海思、海光、中兴微、飞腾）
- **3月8日-14日**：第二梯队投完 + 第一梯队面试
- **3月15日起**：第三梯队补投 + 持续面试
- **4月目标**：拿到至少1个offer

### 投递渠道优先级
1. **内推**（牛客网、EETOP论坛、学长学姐）— 过简历筛选概率最高
2. **BOSS直聘** — 直接和 HR/leader 聊，反馈快
3. **公司官网** — 正式渠道，适合大厂
4. **猎聘/前程无忧** — 补充渠道

### 针对性话术
- **海思/海光**：强调 ECC SECDED、高可靠性设计、Bug 定位能力
- **中兴微/飞腾**：强调 AXI 接口、SoC 集成思维、验证覆盖率
- **芯原/AI方向**：强调 Systolic Array 架构、Weight Stationary、稀疏优化
- **通用**：强调完整的 RTL→仿真→综合 EDA 工具链经验
